This is a pure Kotlin/JS project.

* [/src/main/kotlin](./src/main/kotlin) contains the Kotlin source, compiled to JavaScript for the browser.

### Running the app

```shell
./gradlew jsBrowserDevelopmentRun
```

This starts a dev server with the compiled app.

### Building for production

```shell
./gradlew jsBrowserProductionWebpack
```
